# EasyFlow visual assets

[Contributor guide](../../CONTRIBUTING.md#maintain-the-website-and-visuals) · [Documentation](../../docs/README.md)

The README, user guide, and public website share this directory. GitHub Pages copies it into the site artifact during deployment. Edit the source here; do not maintain a second copy under `website/` or depend on raw files from a different commit.

| File | Purpose |
| --- | --- |
| `easyflow-workspace.svg` | Editable vector explanation of the right-edge Main Panel and inward task details. Clearly labeled example content, not a screenshot. |
| `easyflow-mark.png` | Compact project mark for navigation and the README. |
| `easyflow-app-icon.png` | App icon artwork. |
| `easyflow-hero-poster.png` | Brand poster, also used as the website's social preview. |
| `easyflow-hero-light.webp` / `easyflow-hero-dark.webp` | Existing light/dark brand banners retained for reuse. |

Use illustrations to explain the interaction model without implying they are captured app UI. Keep Main at the selected outer edge and Secondary immediately inward. If adding screenshots, use sample content and record the app version/appearance. Never include private workspace content.
