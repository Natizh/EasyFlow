# EasyFlow v1.5.0

This release makes the edge workspace more reliable and adds native customization and signed in-app updates.

## Highlights

- Main and Secondary stay coordinated during rapid opening, dismissal, display changes, and Space transitions. Fullscreen edge activation no longer activates EasyFlow's ordinary Desktop Space before presenting the panels. The maintainer manually confirmed visible activation over Brave and VS Code fullscreen.
- Settings adds Compact, Classic, Spacious, and Custom panel sizes, direct Width and Height controls, and a Translucent background preference. Classic preserves the previous responsive geometry. The native slider has one evenly spaced ruler, with mouse, keyboard, and VoiceOver adjustment.
- New Task focuses its title immediately. Return creates a task with Effort 1; another effort can be selected first. Imported Apple Reminders remain unrated until assigned locally.
- Settings adds Quit EasyFlow and a clear manual uninstall aid that preserves workspace data and Apple Reminders.
- Public builds add Software Updates: quiet GitHub release checks, release notes, explicit installation approval, Ed25519 verification, SHA-256 integrity checks, and rollback of the installed app on replacement failure.

## First signed updater release

Existing EasyFlow releases have no pinned update key. Install v1.5.0 manually from this GitHub Release to establish the trust chain; subsequent signed releases can be installed in-app. The production Ed25519 public key fingerprint (SHA-256 of its raw 32 bytes) is `189f530cd1c947fd1c34a6e476f2421a16c42cd74a193e8f976fcb92c3a3f7c9`. Only the public key is embedded in the app. The private signing key is never part of the repository or release assets.

EasyFlow is ad-hoc signed and not notarized with an Apple Developer ID. If macOS blocks the first launch of a downloaded build, Control-click the app and choose **Open**, or use **System Settings → Privacy & Security → Open Anyway**. EasyFlow does not disable Gatekeeper or remove quarantine wholesale.

Update installation replaces only the app bundle. The workspace database, attachments, preferences, and Apple Reminders remain in place. See [Signed GitHub updates](../UPDATES.md) for the release format, recovery, and signing procedure.
