Local workspace · focused sync

Your context stays on your Mac.

EasyFlow has no account system, custom backend, telemetry, or analytics. Notes, images, and task details live locally.

With your permission, a dedicated EasyFlow list in Apple Reminders synchronizes the Main Task core. A list in a syncing account makes that core available on your other devices.

Full installation guide
How do updates work?

v1.5.0 introduced signed in-app updates. Manually install that release or a newer public build first. Future verified releases can be installed from Settings. Public builds check GitHub about daily when enabled, and installation requires your action. Ed25519 update verification is separate from Apple notarization. Source builds use a development channel and cannot install public updates in-app.

Can I use it without Apple Reminders?

Yes. Quick Notes and the local workspace remain usable when access is denied. Allow Reminders access when you want Main Task title, completion, and existence to synchronize. Notes, images, Steps, order, and effort remain local either way.

Can I restore a completed task?

The current version has no restore or uncomplete action. Completed Steps stay visible in place; completed Main Tasks leave the active list. Recently Completed shows the five most recent completions, while older completed history remains stored locally.

Where is EasyFlow on a multi-display setup?

Right uses the outer edge of the rightmost display; Left uses the outer edge of the leftmost display. Internal display seams do not activate it. EasyFlow runs without a Dock icon or menu-bar item. Reopen it through Finder or Spotlight for keyboard access.

A note from the creator

A personal tool.
An honest experiment.

Why I made EasyFlow, what I contributed, and how AI helped turn the idea into a working app.

Francesco · Natizh

I am a university student, not a software developer. EasyFlow started because I needed this kind of tool in my own daily work and could not find one that behaved the way I wanted.

Read the full note

I did not personally write the implementation code. My contribution was defining the product: the original idea, project planning and organization, user stories, requirements, interaction details, UX and visual direction, testing decisions, and the many rounds of feedback that shaped the result. I used AI tools to turn that specification into the working macOS application in this repository. The website was created through the same process.

This project is also an honest experiment about the period we are living through. For a product like this, being able to define a problem clearly, communicate with AI, evaluate its output, identify mistakes, and keep iterating was more useful to me than already knowing how to write every line of code myself. That does not make software engineering unimportant; it shows that the ability to direct AI effectively is becoming a real and increasingly important way to build software.

I am not selling EasyFlow, and I do not want to hide or apologize for the fact that it was built with AI. I made it to practice this new way of creating, to keep training my ability to work with AI, and because EasyFlow is genuinely useful to me every day. If it can also be useful to somebody else, even better.
